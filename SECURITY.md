# Security policy

Last Lantern is an offline single-player game, but it reads save files and ships desktop packages, so problems are still possible (for example a crafted save file that runs code, or an unsafe package script).

## Reporting a vulnerability

Please do **not** open a public issue. Use [GitHub's private vulnerability reporting](https://github.com/kalashnikxvxiii/last-lantern/security/advisories/new) instead.

Include what you found, how to reproduce it and the version. You will get an answer within a few days.

## Supported versions

Only the latest commit on `master` and the latest tester package are supported.
