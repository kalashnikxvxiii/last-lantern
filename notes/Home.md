# Last Lantern — shared vault

Team notes for Last Lantern, opened with [Obsidian](https://obsidian.md).
The vault root is the repository itself, so the project docs are part of it.

## Opening the vault

1. Install Obsidian.
2. Choose **Open folder as vault** and pick the repository root (`last-lantern`).
3. The code folders (`js/`, `godot/`, `tools/`, `desktop/`, `dist/`) are hidden
   from the vault by `.obsidian/app.json`.
