# Code of conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

- Be kind and constructive in issues, pull requests and reviews.
- Criticize the code, not the people.
- Welcome newcomers and assume good intent.
- No harassment, discrimination, personal attacks, or publishing other people's private information.

## Enforcement

Maintainers may edit or remove comments, close discussions and block people who break these rules.
Report problems privately to the maintainer through the contact on the GitHub profile [@kalashnikxvxiii](https://github.com/kalashnikxvxiii).
