# Last Lantern

A 2D pixel-art action roguelike. The sun has gone out: you are the last lantern bearer, descending into the Well to rekindle the First Flame, devoured by something that lives at the bottom of the dark.

## Running it

Open `index.html` in a modern browser (Firefox, Chrome, Edge). No installation, server or connection needed: graphics, fonts and audio are all generated by the code.

If your browser blocks local files, serve the folder from anywhere:

```
python3 -m http.server 8000
```

and visit `http://localhost:8000`.

## Godot version (in development)

`godot/` holds the port to Godot 4.7: the whole game, from the Crypts to the Light Devourer and the Infinite Abyss.

    godot --path godot

Tests: `tools/test.sh`. Development arguments go after `--`, for example `godot --path godot -- --test=boss --seed=7`.
The assets in `godot/assets/` were exported once from the JS code with `tools/export_assets/` and are now edited directly.
Windows package for testers of the Godot version: `python3 tools/build_godot.py` (output in `dist/godot/`).

To contribute, read [CONTRIBUTING.md](CONTRIBUTING.md).

## Controls

| Action | Keyboard and mouse | Gamepad |
|---|---|---|
| Move | W A S D | left stick |
| Aim and shoot | mouse + left click, or arrow keys | right stick |
| Dash (invulnerable) | Space / Shift | A, LB |
| Flare (uses oil) | right click / F | B, RB |
| Consumables | 1 2 3 4 | d-pad |
| Interact | E | X |
| Map | Tab / M | Back |
| Pause and equipment | Esc / P | Start |

## The game in brief

- **Five depths** (Crypts, Fungal Caves, Sunken Foundry, Flooded Abyss, Heart of the Well), each generated from rooms and ending with a warden. After the victory you can continue into the Infinite Abyss.
- **The lantern is your life**: oil burns in combat and shrinks your light; slain enemies give it back. Without oil you take more damage. The Flare burns and pushes back enemies and cancels nearby projectiles.
- **Perks** (41) chosen at every level, **relics** (26) from treasures, shops, secrets and wardens, **curses** (8), **consumables** (13) and **status effects** (burning, poison, frost, slow, weakness, frailty, blindness...).
- **23 enemy types** with different behaviors, elite variants with 7 modifiers, **5 bosses** with multiple phases.
- Special rooms: treasure (key required from the second depth), merchant, shrines, challenge halls, secret rooms opened with bombs.
- **Permanent progression**: 5 starting lanterns to unlock and 5 levels of Ardor (difficulty) after the first victory. Progress is saved in the browser.

## Package for testers

```
python3 tools/build.py
```

Creates three archives in `dist/` containing instructions for testers (`README.txt`) and a feedback form:

- `...-Windows.zip`: desktop version for Windows 10/11 x64 (`Last Lantern.exe`).
- `...-Linux.tar.gz`: desktop version for Linux x64 (`start.sh`, plus `install-shortcut.sh` for the applications menu).
- `...-Browser.zip`: the game in a single HTML file, for any system with a browser.

Node.js and npm are required (the first run downloads Electron). Wine is optional and only needed to put the icon on the Windows executable. The version number is changed in `js/core.js` (`VERSION`).

The desktop version saves errors to `error-log.txt` in the user's data folder (`%APPDATA%\Last Lantern` on Windows, `~/.config/Last Lantern` on Linux).

## Structure

```
index.html        page and canvas
js/core.js        constants, utilities, RNG, input, saving
js/font.js        hand-drawn bitmap font
js/gfx.js         sprites, particles, UI panels
js/sprites.js     pixel art (strings)
js/audio.js       sound effects and generative music (WebAudio)
js/data.js        perks, relics, curses, consumables, enemies, bosses, biomes
js/dungeon.js     depth and room generation
js/entities.js    player, enemies, bosses, projectiles, effects
js/render.js      world rendering and lighting
js/ui.js          HUD, minimap, menus
js/game.js        scenes, game flow, main loop
godot/            Godot 4.7 port
desktop/          Electron wrapper (main.js) and packaging script
tools/            package builds, icon generator, tester texts
docs/             porting conventions and playtest checklist
```
